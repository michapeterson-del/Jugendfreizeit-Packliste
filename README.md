# 🎒 Packliste – Jugendfreizeit

Interaktive Packlisten-App, erstellt aus der Vorlage `Packliste_Jugendfreizeit.docx`.
Reine HTML/CSS/JS-App, kein Build-Schritt nötig, läuft komplett im Browser
(Daten werden lokal per `localStorage` gespeichert).

## Features

- ✅ Sachen abhaken – mit Mengen-Zähler (z. B. "Socken 6/9")
- ➕ Eigene Sachen und ganze Kategorien hinzufügen
- 🗑 Sachen und Kategorien entfernen
- 📊 Fortschrittsbalken gesamt + pro Kategorie
- 🎉 Konfetti-Animation, wenn alles gepackt ist
- 🔍 Live-Suche über alle Sachen
- 🌙 Hell-/Dunkelmodus
- 📅 Countdown bis zum Reisedatum
- 📤 Packliste als Text teilen (WhatsApp, etc.) oder in Zwischenablage kopieren
- ⬇️⬆️ Export/Import als JSON-Datei (Backup, Übertragen auf ein anderes Gerät)
- ↺ Alles zurücksetzen (gesamt oder pro Kategorie)
- 📱 Installierbar als App (PWA) und offline nutzbar

## Nutzung

Einfach `index.html` im Browser öffnen, oder den Ordner über GitHub Pages /
einen beliebigen statischen Webserver bereitstellen.

Auf dem Handy kann die Seite über "Zum Startbildschirm hinzufügen" wie eine
echte App installiert werden.
