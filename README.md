# 🎒 Packliste – Jugendfreizeit

Eine coole, interaktive Packlisten-App für die Jugendfreizeit – erstellt aus der ursprünglichen Word-Packliste.

## Features

- ✅ Alle Original-Kategorien & Gegenstände (Hygiene, Kleidung, Snacks, Schuhe, Elektronik, Unterlagen, Sonstiges)
- 📊 Gesamt- und Kategorie-Fortschrittsanzeige (Ring + Balken)
- 🗓️ Countdown bis zum Start der Freizeit
- ➕ Eigene Gegenstände und Kategorien hinzufügen/entfernen
- 🔍 Suche und Filter (Alle / Offen / Gepackt)
- 🌓 Hell-/Dunkelmodus (folgt auch dem Systemthema)
- 🎉 Konfetti-Animation, wenn alles gepackt ist
- 🖨️ Drucken / als PDF speichern
- 📤 Liste teilen oder in die Zwischenablage kopieren
- 💾 Speichert alles automatisch im Browser (localStorage)
- 📱 Installierbar als App (PWA) inkl. Offline-Nutzung

## Nutzung

Einfach `index.html` in einem Browser öffnen, oder die Dateien auf einen beliebigen statischen Webserver (z. B. GitHub Pages) legen.

```bash
python3 -m http.server 8080
# dann http://localhost:8080 öffnen
```

Auf dem Smartphone kann die Seite über "Zum Startbildschirm hinzufügen" wie eine echte App installiert werden.
